这里是一份本地用量账本。账号额度与项目 token 来自不同口径，不能直接换算。

01

账号额度看快照

周额度来自本机日志中最近一次账号快照，可能包含其他设备使用。采样超过一小时会标记过旧；重置后没有新快照时，当前剩余显示未知。刷新不会查询官方实时额度。

02

项目 token 看记录

总量＝输入＋输出。缓存输入是输入的子集，推理是输出的子集；子 Agent 已计入项目与主会话总量，不再额外相加。Token 排名不代表额度成本排名。

03

累计与本周各自统计

累计包含全部现存本机记录，不随周范围切换。日期未知量只进入累计，不能硬放进本周或日趋势。目录项目未检出记录时，实际消耗仍然未知。

04

归属可以人工校正

按手工指定 → 已登记关联 → 项目工作目录 → 未归属的顺序归集；子 Agent 跟随主会话。共享目录、跨项目会话或缺少证据时需要核对。关注和归属仅保存在此看板，不修改 Codex 原始日志。

官方额度说明

项目扣减没有可核对的官方明细，本看板不按 token 分摊额度百分点。
