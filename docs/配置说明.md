# 配置说明

## 常用配置

在仓库根目录创建 `config.json`。它只在本机使用，已经被 `.gitignore` 排除；不要把真实配置上传到公开仓库。

最简单的配置只需要项目总目录：

```json
{
  "workspace": "D:/我的项目"
}
```

支持以下目录结构，只查项目总目录及其下一层分类，不遍历整块硬盘：

```text
我的项目/
  project_001_文档助手/
  工具/
    project_002_数据整理/
  创作/
    project_003_视频创作/
```

项目目录名称不以 `project_` 开头时，可以明确列出：

```json
{
  "workspace": "D:/我的项目",
  "projects": [
    "D:/我的项目/个人网站",
    "D:/其他工作/阅读笔记"
  ]
}
```

## 可选字段

| 字段 | 用途 | 未填写时 |
|---|---|---|
| `workspace` | 项目总目录 | 使用本仓库的上一级目录 |
| `codex_home` | Codex 本地数据目录 | 使用 `CODEX_HOME` 环境变量，未设置则使用当前用户的 `.codex` |
| `projects` | 明确登记的项目完整路径数组 | 空数组，仍会自动发现 `workspace` 中符合规则的项目 |
| `registry` | 可选的会话与项目关联文件 | 不读取外部登记文件 |

路径建议填写完整地址，Windows 也可以使用 `/`。示例路径只是占位符，需改成实际目录。时间显示固定为北京时间。

### 自定义 Codex 数据目录

```json
{
  "workspace": "D:/我的项目",
  "codex_home": "D:/Codex数据"
}
```

数据目录应是包含 `sessions`、`archived_sessions`、以及可选 `state_5.sqlite` 的 Codex 数据根目录，不是某个单独的日志文件。不要提供 API Key，也不要将认证文件复制到本仓库。

### 可选会话登记

仅在你已经知道某个会话属于哪个项目时使用。`registry` 指向一个本机 JSON 文件，结构为：

```json
{
  "entries": [
    {
      "threadId": "在本机核对后的会话ID",
      "projectRoot": "D:/我的项目/project_001_文档助手"
    }
  ]
}
```

没有这个文件也可以使用看板。归属优先级为：手工指定 → 唯一登记关联 → 项目工作目录 → 未归属。子 Agent 跟随主会话；有冲突的关联不会强行猜测。

## 运行与排查

修改配置后，先停止对应看板服务，再重新启动。浏览器刷新只重读用量记录，不重新加载启动配置。

常见情况：

| 现象 | 处理方法 |
|---|---|
| 找不到 Python | 在终端执行 `python --version` 确认可用；本仓库不附带 Python，也不会自动安装依赖 |
| 没有项目 | 核对 `workspace`，或者用 `projects` 列出真实项目目录 |
| 有项目但未检出记录 | 核对 `codex_home` 和会话工作目录；必要时到「会话明细」补充归属 |
| 当前额度未知 | 本机没有有效快照；可查看累计或主动选择近 7 天，不能据此判定额度为零 |
| 新记录没有出现 | 点击「刷新记录」；仅靠浏览器停留不会持续重扫所有文件 |
| 43129 端口被占用 | 先确认是否已有本看板；启动脚本不会结束其他程序。命令行可用 `--port 43130` 另开端口 |
| 扫描失败 | 到「统计口径」查看提示；使用启动脚本时也可查看本机 `03_数据/服务错误.log` |

看板的缓存、手工归属和关注保存在 `03_数据` 中。停止服务后可以备份这个文件夹，但其中包含个人会话元数据和路径，请作为私有数据保存。

当前以 Windows 为主要验证环境；其他系统的路径处理、启动入口和 Codex 日志兼容性尚未完成独立验证。日志格式变化导致的读取问题，请提交去除个人信息的最小样例。
